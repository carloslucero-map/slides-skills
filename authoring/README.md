# authoring/

Material the `wpp-es-html-deck` skill was **made from**, kept out of the skill
directory so it cannot count against the 30 MB claude.ai upload cap.

Nothing here is read while a deck is being built. Every reference to these
paths in the tree is in the tool that writes them.

| | |
|---|---|
| `canon-shots/` | Contact sheets from `wpp-es-html-deck/scripts/shoot_snippets.py` — 51 snippet renders plus per-archetype sheets, and `VERDICTS.md`. The review surface: most of what is wrong with a template is visible in a PNG in seconds and invisible to every assertion in the verifier. |
| `canon-ref/` | The source deck the 25 canon templates were traced from — `renders/` at full resolution, `measure/`, and `manifest.json` joining curated selection to bank page order. Regenerated by `canon/_tools/build_ref_manifest.py`. |

Both were inside `wpp-es-html-deck/canon/` as `_shots/` and `_ref/` until they
put the skill directory 25 MB over the cap. They moved, they did not go away:
they are what the canon is re-derived from, and what design work reads.

`shoot_snippets.py` now defaults `--out` here. `package_skill.py` reports the
skill directory size on every run, so a regression surfaces at packaging time
rather than at upload time.
